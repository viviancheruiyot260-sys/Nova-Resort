# Nova Resort 🌿

**Stay. Dine. Unwind. Connect.**

Nova Resort is a hospitality website created as part of my web development assignment at eMobilis. The website showcases a resort offering comfortable accommodation, restaurant services, fitness facilities, and conference and event spaces.

## ✨ Features

- **Home:** An introduction to Nova Resort with an attractive hero section.
- **Services:** Highlights accommodation, restaurant, gym, and conference facilities.
- **Contact Us:** A contact form for visitors to make inquiries.
- **Navigation:** Simple navigation links that take visitors to different sections of the page.
- **Elegant Design:** A clean layout featuring a dark green and gold color theme.

## 🛠️ Technologies Used

- HTML5
- CSS3
